# Online-Street-Vendors-Marketplace
An online marketplace for street vendors to introduce and sell their products.
# بازارچه آنلاین دست‌فروشان
Online Street Vendors Marketplace

1. معرفی محصول
بازارچه آنلاین دست‌فروشان سامانه‌ای است که با هدف
معرفی محصولات دست‌فروشان و ایجاد ارتباط آسان‌تر
میان فروشندگان و مشتریان طراحی می‌شود.

این سامانه به فروشندگان کمک می‌کند محصولات خود را
به‌صورت آنلاین معرفی کنند و مشتریان بتوانند بدون
نیاز به مراجعه حضوری، محصولات مختلف را مشاهده کنند.

2. مسئله و نیاز محصول
بسیاری از دست‌فروشان برای معرفی محصولات خود و
دسترسی به مشتریان بیشتر با محدودیت روبه‌رو هستند.
از طرف دیگر، مشتریان ممکن است برای پیدا کردن
محصول موردنظر خود مجبور به مراجعه به مکان‌های
مختلف شوند.

این سامانه با هدف آسان‌تر کردن معرفی محصولات،
افزایش دسترسی مشتریان و ایجاد بستری برای ارتباط
میان فروشندگان و خریداران طراحی می‌شود.

3. اهداف پروژه
- کمک به معرفی محصولات دست‌فروشان
- افزایش دسترسی فروشندگان به مشتریان
- آسان‌تر کردن جست‌وجوی محصولات
- نمایش قیمت و مشخصات کالاها
- ایجاد بستری برای ارتباط خریداران و فروشندگان
- کمک به گسترش فعالیت فروشندگان کوچک

4. ویژگی‌های اصلی محصول
- ثبت‌نام و ورود کاربران
- ایجاد حساب کاربری فروشندگان
- ثبت اطلاعات فروشندگان
- افزودن محصولات جدید
- ویرایش و حذف محصولات
- نمایش نام، تصویر، قیمت و توضیحات محصولات
- دسته‌بندی محصولات
- جست‌وجوی محصولات
- مشاهده اطلاعات تماس فروشنده
- مشاهده فهرست محصولات هر فروشنده
- مدیریت کاربران و محصولات توسط مدیر سامانه

5. مخاطبان محصول
- دست‌فروشان
- فروشندگان کوچک
- خریداران
- افرادی که به دنبال محصولات متنوع هستند
- مدیران سامانه

6. فناوری‌های پیشنهادی
فناوری‌های زیر به‌عنوان گزینه‌های اولیه برای
پیاده‌سازی پروژه در نظر گرفته می‌شوند:

- HTML برای ساختار صفحات وب
- CSS برای طراحی و ظاهر صفحات
- JavaScript برای ایجاد تعامل با کاربران
- Python برای پیاده‌سازی منطق سمت سرور
- SQLite برای ذخیره اطلاعات کاربران و محصولات
- Git و GitHub برای مدیریت نسخه‌ها و مستندات پروژه

انتخاب نهایی فناوری‌ها در مراحل بعدی پروژه
و بر اساس نیازمندی‌های سامانه انجام خواهد شد.

7. نقشه راه اولیه
1. شناسایی نیازهای فروشندگان و مشتریان
2. تعیین نیازمندی‌های سامانه
3. طراحی صفحات و ساختار بازارچه
4. طراحی پایگاه داده
5. پیاده‌سازی ثبت‌نام و ورود کاربران
6. پیاده‌سازی ثبت و نمایش محصولات
7. ایجاد قابلیت جست‌وجو و دسته‌بندی
8. آزمایش امکانات و رفع خطاها
9. آماده‌سازی نسخه نهایی پروژه

8. نتیجه مورد انتظار
انتظار می‌رود این سامانه بستری ساده و کاربردی
برای معرفی محصولات دست‌فروشان فراهم کند و
دسترسی مشتریان به محصولات متنوع را آسان‌تر سازد.
